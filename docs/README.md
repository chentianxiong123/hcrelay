## 背景

hcrelay 是「手机当 DLNA 中继」的项目：手机同时扮演 DLNA 接收端（骗过 App）
和发送端（推给真实电视），中间做 HLS 播放列表重写 + 分片反向代理。

这两篇文档记录了开发过程中的两个关键问题：
1. **HLS 全 404** —— 电视能解析 m3u8 但分片全失败，根因是相对路径丢目录。
2. **转码能力** —— 当遇到"放不了"的源（HEVC/VP9/AV1），手机能否 CPU 转码兜底。
